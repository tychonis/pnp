# Cyanotype Example: Pick and Place machine

This repository provides a machine-readable Bill of Materials (BoM) example for the [Opulo LumenPnP](https://github.com/opulo-inc/lumenpnp), created using the [Cyanotype](https://tychonis.com/) BoM-as-code system.
